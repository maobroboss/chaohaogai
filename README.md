# 超好蓋 — PDF 貼簽名、貼印章、騎縫章

免費、開放給所有人使用的 PDF 蓋章工具。所有檔案只在你的瀏覽器裡處理，**不會上傳到任何伺服器**。

## 直接使用（線上版）

👉 https://gai.maobro.com/

## 下載離線版（不需要網路）

👉 到 [Releases](../../releases/latest) 下載 `chaohaogai-offline.html`（超好蓋離線版），存到電腦後用 Chrome / Edge / Safari 打開即可。

## 功能

- 拍照或掃描的簽名／印章自動去背（光線不均、陰影也能處理）
- 自動矩形修正：拍歪的印章拉正、正方章拉成正方形；也可手動拖四角
- 一張照片多個章可自動分拆
- 依實際尺寸貼上（掃描檔自動換算；拍照的填印章寬度即可）
- 騎縫章：自動切條分蓋多頁、可預覽錯開疊起的效果
- 手寫簽名、多頁貼章、簽章庫自動保存
- 手機也能用
